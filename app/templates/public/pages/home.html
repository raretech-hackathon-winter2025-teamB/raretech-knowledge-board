主な機能

{% include "app/components/icons/chat.svg" with icon_class="w-8 h-8" %}

質問投稿機能

マークダウンエディタを使って、コードや画像を含めた質問を簡単に投稿できます。プレビュー機能で投稿前に確認も可能です。

{% include "app/components/icons/search.svg" with icon_class="w-8 h-8" %}

検索・絞り込み

キーワード検索、カテゴリー・タグでの絞り込み、解決済み/未解決のフィルタリングで、必要な情報をすぐに見つけられます。

{% include "app/components/icons/bookmark.svg" with icon_class="w-8 h-8" %}

ブックマーク機能

気になる質問や役立つ回答をブックマークして、後から簡単に見返すことができます。学びの記録として活用できます。

{% include "app/components/icons/community.svg" with icon_class="w-8 h-8" %}

コミュニティ

エンジニア同士が助け合い、知識を共有するコミュニティです。初心者からベテランまで誰でも質問・回答できます。

{% include "app/components/icons/book-guide.svg" with icon_class="w-8 h-8" %}

質問ガイド

「いい質問の仕方」ガイドで、効果的な質問の書き方を学べます。より早く、より良い回答を得られるようになります。

{% include "app/components/icons/star.svg" with icon_class="w-8 h-8" %}

マイページ

自分の質問・回答を一覧で管理できます。プロフィール編集やマイページ設定も簡単に変更できます。
