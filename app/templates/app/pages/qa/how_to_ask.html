いい質問の仕方

質問投稿へ

エンジニアとして効果的な質問をするために

ITエンジニアにとって、技術的な問題を正確に伝える能力は非常に重要です。 適切な質問をすることで、より早く、的確な回答を得ることができます。

このガイドでは、相手に状況を詳細に伝え、問題解決につながる質問の仕方を学びます。

質問に含めるべき5つの要素

1. 何を実現したいのか（目的）

最終的に達成したいゴールを明確に述べましょう。

例：「ユーザーがログインした後、マイページに自動遷移する機能を実装したい」

2. 現在の状況（何が起きているか）

実際に発生している問題や動作を具体的に説明しましょう。

例：「ログイン処理は成功するが、画面が真っ白になり、コンソールに『Cannot read property 'name' of undefined』というエラーが表示される」

3. 期待する動作（本来どうあるべきか）

正しく動作した場合、どうなるべきかを明示しましょう。

例：「ログイン後、ユーザー名が表示されたマイページ（/mypage）に遷移する」

4. 試したこと（デバッグの過程）

自分で試みた解決策や調査内容を共有しましょう。

例：「console.logでユーザーデータを確認したが、undefinedが返ってきた。APIのレスポンスは200で成功している。公式ドキュメントを確認し、同じ記述をしているが解決しない」

5. 環境情報

開発環境や使用している技術スタックを記載しましょう。

例：「React 18.2.0、Next.js 14.0.0、Node.js 20.10.0、macOS Sonoma」

コードやエラーの提示方法

✅ 良い例

コードブロックを使用し、該当箇所を明確に示す：

```javascript
// Login.jsx の該当部分（30-45行目）
const handleLogin = async (userData) => {
  const response = await fetch('/api/login', {
    method: 'POST',
    body: JSON.stringify(userData)
  });
  const data = await response.json();
  console.log(data); // → undefined が出力される
  setUser(data.user.name); // ← ここでエラー
};
```

❌ 悪い例

スクリーンショットのみ、または説明が不十分：

「エラーが出ます。どうしたらいいですか？」（コードもエラーメッセージもなし）

💡 ポイント

  • •マークダウンのコードブロック（```）を使用する
  • •行番号やファイル名を記載する
  • •エラーメッセージは全文をコピー＆ペーストする
  • •必要最小限のコードに絞る（全体ではなく該当部分）
  • •スクリーンショットは補足として使用し、テキストも併記する

再現手順の書き方

問題を再現できる手順を番号付きで明確に記載しましょう。

✅ 良い例

  1. ログイン画面（/login）にアクセス
  2. メールアドレスに「test@example.com」、パスワードに「password123」を入力
  3. 「ログイン」ボタンをクリック
  4. ネットワークタブで200レスポンスを確認
  5. → 画面が真っ白になり、コンソールにエラーが表示される

環境情報のチェックリスト

フロントエンド

  • フレームワーク・ライブラリのバージョン
  • ブラウザの種類とバージョン
  • デバイス（PC / スマホ / タブレット）

バックエンド

  • 使用言語とバージョン
  • フレームワークとバージョン
  • データベースの種類とバージョン

インフラ・環境

  • OS（Windows / macOS / Linux）
  • 開発環境（ローカル / Docker / AWS等）
  • Node.jsやPythonのバージョン

その他

  • エディタ・IDE
  • 使用している主要なパッケージ
  • エラーが発生する環境（本番 / 開発）

コミュニケーションのマインドセット

🎯 相手の時間を尊重する

必要な情報を一度に提供することで、何度もやり取りする手間を省き、効率的に問題を解決できます。

🔍 自分で調べた痕跡を示す

「公式ドキュメントを確認しました」「Stack Overflowで類似の質問を探しました」など、自分で試みた調査を共有することで、より的確な回答が得られます。

💬 専門用語を正確に使う

「エラー」「バグ」「動かない」といった曖昧な表現ではなく、「404エラー」「nullポインタ例外」「レスポンスが返ってこない」など具体的に表現しましょう。

📝 タイトルも具体的に

質問のタイトルは検索可能で、一目で内容がわかるようにしましょう。

❌「エラーが出ます」
✅「React Routerでログイン後のリダイレクトでTypeError: Cannot read property 'name' of undefined」

📋 完全な質問の例

タイトル:

Next.js 14でAPIルートからのレスポンスがundefinedになる問題

質問内容:

## 実現したいこと

ユーザーがログインした後、APIからユーザー情報を取得してマイページに表示したい。

## 現在の状況

ログイン処理は成功し、APIは200レスポンスを返すが、取得したデータがundefinedになり、画面が真っ白になる。コンソールに「TypeError: Cannot read property 'name' of undefined」が表示される。

## 該当コード

```javascript
// pages/mypage.jsx (25-35行目)
const fetchUserData = async () => {
  const response = await fetch('/api/user');
  const data = await response.json();
  console.log('Response:', data); // → undefined
  setUserName(data.user.name); // ← エラー発生
};
```

## 試したこと

  • console.logでresponseを確認 → statusは200で成功
  • Postmanで直接APIを叩く → 正しくデータが返ってくる
  • Next.jsの公式ドキュメントを確認 → 同じ書き方をしている

## 環境

  • Next.js: 14.0.4
  • React: 18.2.0
  • Node.js: 20.10.0
  • OS: macOS Sonoma 14.2
  • ブラウザ: Chrome 120.0
